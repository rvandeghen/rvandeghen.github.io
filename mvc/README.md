# MVC project page

Static project page for **Advancing Video-Text Pretraining with Multi-View Captions**.

The page includes two short InternVid video examples with their original and MVC captions, the captioning pipeline figure, the dual-<code>CLS</code> training objective, and the paper's standard zero-shot, fine-tuned, and fine-grained zero-shot tables with Baseline-B and MVC results at 5M and 10M.

## Main assets

- assets/mvc-pipeline.png — captioning pipeline figure from the manuscript source.
- assets/videos/outdoor-wok.mp4 — 19.9-second InternVid example.
- assets/videos/bocce-game.mp4 — 10.8-second InternVid example.
